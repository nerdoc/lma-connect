Cache busting uses the version token IN THE PATH of the icon URL (icon-180-.png), NOT as a ?query: iOS/Safari ignore apple-touch-icon URLs carrying a query string and fall back to the grey letter placeholder. The token is event.icon_version (logo mtime plus render revision), NOT event.logo_version: Safari remembers per URL that an icon fetch failed and never retries it, so an icon fixed in the renderer but served under an unchanged URL never reaches the device. The apple-touch-icon points at the OPAQUE variant (icon-opaque-…): Safari discards home-screen icons with an alpha channel.
