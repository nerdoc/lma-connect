{% load i18n %} {% comment %} Server error page. django.views.defaults.server_error renders this template WITHOUT a request and WITHOUT context processors (template.render() with no arguments) — so there is NO {{ event }}, no {{ request }}, no csp_nonce and no CSRF token here. Hence it is deliberately SELF-CONTAINED: no {% templatetag openblock %} extends "base.html" {% templatetag closeblock %}, no CDN assets, no {% templatetag openblock %} url {% templatetag closeblock %} resolution (hard-linked to "/"). That way the page still renders while the app is in a broken state. It stays translatable all the same. This is also the one place that may hard-code brand colours: without an event there is nothing to read them from.
